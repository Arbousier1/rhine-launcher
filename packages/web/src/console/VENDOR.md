## 保留的基线

真实 cassette / assembly GLB、原相机轨迹、阵列与波浪、垂直抽取、旋转归正后下降、解密过程、开场编排、原生 DOM 布局、配色过渡、音频和滚动文字。不是另造相似色调的托盘。

- Three.js 固定为原锁文件使用的 0.183.2；类型为 0.183.1。
- rolling-number 0.4.1 的缩放测量修补以 pnpm patch 保存，采用上游相同替换。
- MiSans 4.3.1：753 个原始 WOFF2 分片及 8 个说明/许可文件，字节级恢复；原字体 CSS 不变。
- 不取得或伪装授权使用原站 Novecento 商业字体包，继续采用上游供衍生项目使用的 authored-art fallback。

## 有意修改的接缝

1. 原静态故事档案改为真实目录：默认有名称的实例，安装目录另按发布渠道和版本系列筛选；无记录和请求失败明确区分。
2. 原选档标题显示实例名称/游戏版本；载体文字与选中记录同源。内部编号降为辅助信息。
3. 启动、停止、账号选择和新建配置占用原详情文章区域；先前外置绝对定位的启动面板已移除。
4. 非拖拽的真实点击增加激活回调，选择并抽取同一记录；不改写相机、波浪或升降方程。
5. 原 main 改为可逆 Cordis 组件挂载，游戏操作通过独立 capability 调用；平台事件、帧循环、定时器、音频、模型、滚动控件与字幕注册表拥有清理逆操作。模型请求增加取消信号。
6. 本地应用不注册原站 service worker。CSS 行尾统一为 LF；启动器语义样式在单独文件中，不覆盖成另一套界面。

这份源码不是“完全未改动”，也不是“仅加了三个按钮”。图形基线保留，数据、输入激活与资源生命周期是明确的接入层。
